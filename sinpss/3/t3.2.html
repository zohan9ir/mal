Sinopsis>>> Francis se emancipa y trata de tener una charla con Lois para poder aclarar la situación pero ella se niega a escucharlo, mientras, Malcolm tiene un nuevo maestro, quien somete a todo el grupo Krelboyne con un estricto sistema educativo, diseñado para denigrar a todos los inteligentes.
